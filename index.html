ตั้งค่าระบบ
ใส่ URL ของ Google Apps Script Web App ที่ Deploy แล้ว — ไม่ต้องแก้ไฟล์ HTML อีก
ค่าจะถูกเก็บไว้ในเบราว์เซอร์นี้ และใช้ทุกครั้งที่เปิดหน้าเว็บ
หมายเหตุ:
• URL ต้องมาจาก Apps Script ที่ Deploy แบบ Execute as: Me และ Who has access: Anyone
• รหัสผ่านผู้ใช้ (developer/viewer) จัดการที่ Apps Script → Script Properties ชื่อ CULAC_PWD
• ถ้าไม่ตั้งค่า URL ระบบจะทำงานออฟไลน์ (ใช้ข้อมูลในเครื่อง + DEMO)
